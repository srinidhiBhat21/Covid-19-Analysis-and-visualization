# 🦠 COVID-19 India Status Dashboard

An interactive **COVID-19 India Status Dashboard** developed to analyze COVID-19 cases, recoveries, deaths, active cases, and state-wise performance across India.

## 📊 Project Overview

This project uses data visualization and analytics to provide a clear overview of COVID-19 statistics across Indian states and union territories.

The dashboard analyzes:

- Total COVID-19 cases
- Active cases
- Discharged/recovered cases
- Deaths
- Active case ratio
- Discharge ratio
- Death ratio
- State-wise COVID-19 performance

## 🛠️ Tools & Technologies

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development

## 📌 Key KPIs

- Total Cases
- Active Cases
- Total Discharged
- Total Deaths
- Active Ratio
- Discharge Ratio
- Death Ratio

## 📈 Dashboard Features

### 🗺️ State-wise Analysis
Compare COVID-19 cases, recoveries, and deaths across different Indian states and union territories.

### 📊 Case Analysis
Analyze the distribution of total cases, active cases, discharged cases, and deaths.

### 📈 Recovery Analysis
Compare discharge ratios across states to understand recovery performance.

### ⚠️ Mortality Analysis
Analyze death counts and death ratios across different states.

## 💡 Key Insights

- Maharashtra recorded the highest number of total COVID-19 cases among the states in the dataset.
- Kerala and Karnataka were also among the states with the highest reported case counts.
- Maharashtra recorded the highest number of reported deaths.
- Discharge ratios were above 99% in many states and union territories.
- Punjab recorded the highest death ratio in the dataset, followed by Nagaland and Maharashtra.
