# 🦠 COVID-19 India Status Dashboard

An interactive **COVID-19 India Status Dashboard** developed to analyze and visualize COVID-19 cases, active cases, recoveries, deaths, and state-wise performance across India.

## 📊 Project Overview

This project focuses on transforming COVID-19 data into meaningful visual insights through an interactive dashboard.

The dashboard provides a comprehensive view of India's COVID-19 situation and enables analysis of:

- Total COVID-19 cases
- Active cases
- Discharged/Recovered cases
- Deaths
- Active case ratio
- Discharge ratio
- Death ratio
- State-wise COVID-19 statistics

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- **Data Cleaning**
- **Data Analysis**
- **Data Visualization**
- **Dashboard Development**

## 📌 Key KPIs

- Total Cases
- Active Cases
- Total Discharged
- Total Deaths
- Active Ratio
- Discharge Ratio
- Death Ratio

## 📈 Dashboard Features

### 🗺️ State-wise Analysis
Compare COVID-19 cases, recoveries, and deaths across different Indian states and union territories.

### 📊 Case Analysis
Analyze the distribution of total cases, active cases, discharged cases, and deaths.

### 💚 Recovery Analysis
Compare discharge ratios across states to understand recovery patterns.

### ⚠️ Mortality Analysis
Analyze death counts and death ratios across different states.

## 💡 Key Insights

- Maharashtra recorded the highest number of total COVID-19 cases among the states in the dataset.
- Maharashtra also recorded the highest number of reported deaths.
- Several states and union territories recorded discharge ratios above 99%.
- Punjab recorded the highest death ratio among the states in the dataset.
- State-wise analysis highlights significant differences in COVID-19 case and recovery patterns across India.

## 📂 Dataset

The project uses a **state-wise COVID-19 India dataset** containing information about:

- State/UT
- Total Cases
- Active Cases
- Discharged Cases
- Deaths
- Active Ratio
- Discharge Ratio
- Death Ratio
- Population
