
# 📁 COVID-19 India Dataset

This folder contains the dataset used to develop the **COVID-19 India Status Dashboard**.

## 📄 Dataset

**File:** `Latest-Covid-19-India-Status.csv`

The dataset contains state-wise COVID-19 statistics for Indian states and union territories.

## 📊 Dataset Columns

| Column | Description |
|---|---|
| State/UTs | Name of the Indian state or union territory |
| Total Cases | Total reported COVID-19 cases |
| Active | Number of active COVID-19 cases |
| Discharged | Number of discharged/recovered cases |
| Deaths | Number of reported deaths |
| Active Ratio | Percentage of total cases that were active |
| Discharge Ratio | Percentage of total cases that were discharged |
| Death Ratio | Percentage of total cases resulting in death |
| Population | Population associated with the state/UT |

## 🔍 Data Analysis

The dataset was used to analyze:

- State-wise total COVID-19 cases
- Active case distribution
- Recovery/discharge performance
- State-wise deaths
- Discharge ratios
- Death ratios
- Comparison between states and union territories

## 📈 Dataset Summary

The dataset contains COVID-19 statistics for multiple Indian states and union territories.

Key aggregated metrics include:

- **Total Cases:** 44.99 Million+
- **Active Cases:** 1,812
- **Discharged Cases:** 44.46 Million+
- **Deaths:** 532,027

## 💡 Key Observations

- Maharashtra has the highest total case count in the dataset.
- Maharashtra also has the highest reported number of deaths.
- Several states have discharge ratios above 99%.
- Punjab has the highest death ratio among the states in the dataset.
